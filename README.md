# Сайт Укрмʼясо

Готовый сайт на HTML, CSS и JavaScript. Сборка, npm и React не нужны. Действующий адрес: https://ukrmiaso.com/. Хостинг — HOSTiQ.

## Открыть в VS Code

В VS Code выберите **File → Open Folder…** и откройте эту папку целиком. На этом Mac уже установлены VS Code, GitHub Desktop и Python 3.

Для предпросмотра выберите **Terminal → Run Task… → Сайт: предпросмотр**, затем откройте http://127.0.0.1:8765/. Терминал должен оставаться запущенным; остановить сервер можно клавишами Control+C.

## Заменить прайс

1. В Finder выделите новый PDF и нажмите **Option+Command+C** — скопируется полный путь к файлу.
2. В VS Code выберите **Terminal → Run Task… → Сайт: заменить прайс PDF**.
3. Вставьте путь и укажите дату, напечатанную в прайсе, в формате `2026-10-01`.
4. Обновите предпросмотр и нажмите «Завантажити прайс». Скрипт сам скопирует PDF, обновит ссылки на обеих страницах, дату и версии файлов для обновления кеша.

Цены и характеристики отдельных товаров хранятся отдельно в `assets/products.js`. Замена PDF не переписывает их автоматически. Старые PDF остаются в папке как резервные файлы.

## Заменить или добавить фото товара

1. Откройте `assets/products.js`, найдите название товара через Command+F и посмотрите его поле `id`.
2. В Finder скопируйте путь к фотографии через **Option+Command+C**.
3. В **Terminal → Run Task…** выберите **Сайт: заменить фото товара** или **Сайт: добавить второе фото товара**.
4. Укажите `id` и путь. Скрипт скопирует фото в `assets`, обновит запись товара и версии файлов.
5. Проверьте фото в каталоге и в подробном окне. JPG, PNG и WebP поддерживаются; обработку фона скрипт не делает.

Вручную это тоже можно сделать: положить файл в `assets`, затем указать путь в поле `image` товара. Дополнительные фотографии перечисляются в `extraImages`, например `["assets/second-photo.jpg"]`.

## Отправить изменения на действующий сайт

Изменения в VS Code и GitHub сами по себе не меняют сайт на HOSTiQ.

1. Проверьте предпросмотр, затем запустите задачу **Сайт: собрать ZIP для HOSTiQ**. Путь к архиву появится в терминале; архив лежит рядом с папкой сайта.
2. В HOSTiQ откройте **cPanel → Менеджер файлов**. Сохраните копии изменяемых файлов сайта в домашней папке хостинга для отката.
3. Загрузите ZIP в домашнюю папку `/home2/ukrmiaso`, затем выберите его и нажмите **Извлечь**.
4. Путь распаковки: `/public_html`. Файлы действующего сайта будут обновлены. Не указывайте другую папку и не загружайте ZIP внутрь публичного каталога.
5. Откройте https://ukrmiaso.com/ и проверьте фото, каталог и прайс.

ZIP содержит только файлы сайта и `assets`. В него не попадают README, настройки редактора, инструменты и история Git. Все файлы упаковываются с правами 0644 и актуальной датой.

## GitHub

Репозиторий: https://github.com/OlgaMunaieva/ukrmiaso. Предпросмотр GitHub Pages: https://olgamunaieva.github.io/ukrmiaso/. Основной сайт https://ukrmiaso.com/ остаётся на HOSTiQ.

На этом Mac подготовленная папка уже подключена к репозиторию. На другом компьютере в VS Code выберите **Source Control → Clone Repository**, вставьте адрес репозитория и откройте скачанную папку. Не создавайте второй репозиторий через Publish to GitHub. Войдите в свой аккаунт GitHub, если редактор попросит.

После редактирования проверьте список изменений в **Source Control** (значок ветки слева), добавьте нужные файлы кнопкой **+**, напишите описание, например «Новый прайс», нажмите **Commit**, затем **Sync Changes**. Это сохранит новую версию на GitHub и запустит обновление GitHub Pages. Публикацию на HOSTiQ выполняйте отдельно по инструкции выше.

Старый сайт сохранён в истории коммитов до обновления от 10 октября 2026 года. В **Timeline** можно посмотреть предыдущие версии файлов. Перед редактированием на нескольких компьютерах нажимайте **Sync Changes**, чтобы получить последние изменения.

Документация: [GitHub в VS Code](https://code.visualstudio.com/docs/sourcecontrol/github), [публикация репозитория](https://code.visualstudio.com/docs/sourcecontrol/repos-remotes).

## Где что находится

| Файл | Назначение |
|---|---|
| `index.html` | Главная страница и фото главного слайдера |
| `catalog.html` | Страница каталога |
| `assets/products.js` | Названия, характеристики и фотографии товаров |
| `assets/` | Фотографии, логотип, прайс, карточка для мессенджеров |
| `style.css` | Дизайн, мобильная версия и тёмная тема |
| `app.js` | Каталог, языки, слайдеры и анимация бычка |
| `theme.js` | Выбор и сохранение темы |
| `tools/manage_site.py` | Локальные задачи замены фото/прайса и упаковки |

Пароли хостинга, токены и настройки соединения храните вне репозитория. `.gitignore` уже исключает распространённые локальные файлы с настройками доступа.
